Luna POS — System Architecture

Self-hosted PocketBase · Tailscale VPN mesh · Expo Android APK + Next.js Admin

Transaction Flow (Tablet)

  • 1. App starts → fetches available products via REST
  • 2. SSE subscription keeps product list live
  • 3. Cashier taps products → Zustand cart accumulates
  • 4. Tap Charge → Checkout screen + QRIS displayed
  • 5. Customer scans QRIS, pays via e-wallet/bank
  • 6. Cashier taps "Payment Received"
  • 7. POST /orders + /order_items to PocketBase
  • 8. Cart clears → auto-nav back to POS in 3s

Migration: Supabase → PocketBase

  • • npm remove @supabase/supabase-js @supabase/ssr
  • • npm add pocketbase
  • • EXPO_PUBLIC_SUPABASE_URL → EXPO_PUBLIC_API_URL
  • • supabase.from('x').select() → pb.collection('x').getList()
  • • supabase.from('x').insert() → pb.collection('x').create()
  • • RLS policies → PocketBase collection rules
  • • Supabase tables → recreated as PB collections
  • • Admin Next.js: same pages, new SDK calls

Setup Checklist

  • ☐ Install Tailscale on MacBook + Android tablet
  • ☐ Download pocketbase binary → ~/Project/luna-pos/
  • ☐ Run: caffeinate -i ./pocketbase serve --http=0.0.0.0:8090
  • ☐ Open /_/ → create admin account + collections
  • ☐ Note Tailscale IP (100.x.x.x) → set in tablet .env
  • ☐ Update admin Next.js: swap SDK + point to :8090
  • ☐ Build new APK with eas build
  • ☐ Backup = copy pb_data/ folder periodically
